# Скальпер Дашборд - Si-12.26

Интерфейс для отслеживания открытых позиций физических и юридических лиц по фьючерсному контракту Si-12.26 (доллар США - рубль) в реальном времени.

## Быстрый старт

### 1. Настройка API ключа

Создайте файл `api_key.txt` в этой директории и вставьте туда ваш MOEX Algopack API ключ:

```
ваш_api_ключ_сюда
```

### 2. Запуск сервера

Откройте терминал в этой директории и выполните:

```bash
python server.py
```

### 3. Открыть дашборд

После запуска сервера откройте в браузере:

- **Дашборд**: http://localhost:8080/scalper-dashboard.html
- **Тест API**: http://localhost:8080/test-api.html

## Возможности

- 📊 **Real-time данные** - обновление каждые 10 секунд
- 🌙 **Тёмная тема** - комфортная работа в любое время
- 🇷🇺 **Русский язык** - полный перевод интерфейса
- 👤 **Физические лица** - объёмы лонг/шорт позиций
- 🏢 **Юридические лица** - объёмы лонг/шорт позиций
- 📈 **Детализация** - количество трейдеров, средний объём
- ⚖️ **Сравнение** - разница между категориями
- 🕐 **Московское время** - автоматическая синхронизация (UTC+3)

## Технические детали

- **API**: MOEX Algopack FUTOI (Futures Open Interest)
- **Обновление данных**: каждые 5 минут на стороне MOEX
- **Обновление интерфейса**: каждые 10 секунд
- **Прокси-сервер**: решает проблему CORS и безопасно хранит API ключ

## Решение проблем

### Данные не отображаются

1. Проверьте, что сервер запущен (`python server.py`)
2. Убедитесь, что файл `api_key.txt` существует и содержит правильный ключ
3. Откройте консоль браузера (F12) и проверьте ошибки
4. Используйте тест API: http://localhost:8080/test-api.html

### Ошибка "Failed to fetch"

Это означает, что вы открываете HTML файл напрямую, а не через сервер.
Обязательно запускайте `python server.py` и открывайте дашборд через http://localhost:8080/

### Ошибка авторизации

- Без API ключа: данные доступны только за последние 15 дней (ограничение MOEX)
- С API ключом: real-time данные (обновление каждые 5 минут)

## Остановка сервера

Нажмите `Ctrl+C` в терминале, где запущен сервер.
