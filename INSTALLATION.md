# Инструкция по установке и запуску MOEX Scalper Dashboard

## Требования

1. **Python 3.8+** - [Скачать Python](https://www.python.org/downloads/)
   - При установке на Windows обязательно отметьте галочку **"Add Python to PATH"**

2. **API ключ MOEX Algopack** - [Получить ключ](https://algopack.moex.com/)
   - Требуется платная подписка для получения данных в реальном времени
   - Без подписки данные будут с задержкой 14 дней

## Установка

### 1. Распакуйте архив

Распакуйте ZIP-архив в любую папку, например:
```
C:\Users\YourName\moex-scalper-dashboard
```

### 2. Создайте файл с API ключом

В папке проекта создайте файл **`api_key.txt`** и вставьте туда ваш MOEX API ключ.

Файл должен содержать **только** ключ, без пробелов и переносов строк:
```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 3. Запустите сервер

#### Windows:
1. Откройте **Командную строку** (cmd) или **PowerShell**
2. Перейдите в папку проекта:
   ```cmd
   cd C:\Users\YourName\moex-scalper-dashboard
   ```
3. Запустите сервер:
   ```cmd
   python server.py
   ```

Вы должны увидеть сообщение:
```
[OK] API ключ загружен из api_key.txt (длина: 1669 символов)
[SERVER STARTED] MOEX FUTOI API Proxy Server запущен
[OK] Порт: 8081
[OK] Дашборд: http://localhost:8081/scalper-dashboard.html
```

**НЕ ЗАКРЫВАЙТЕ** это окно, пока используете дашборд!

#### Автоматический запуск (Windows):
Дважды кликните на файл **`start.bat`** (если он есть в папке).

### 4. Откройте дашборд

Откройте браузер и перейдите по адресу:
```
http://localhost:8081/scalper-dashboard.html
```

## Решение проблем

### Ошибка "Failed to fetch"

**Причина:** Сервер не запущен.

**Решение:**
1. Убедитесь, что сервер запущен (см. шаг 3)
2. Проверьте, что в консоли сервера нет ошибок
3. Попробуйте открыть `http://localhost:8081/test-api.html` для тестирования API

### Ошибка "Free users can't receive data for the last 14 days"

**Причина:** У вас бесплатная подписка MOEX Algopack.

**Решение:**
1. Приобретите платную подписку на [MOEX Algopack](https://algopack.moex.com/)
2. Или используйте данные с задержкой (дашборд автоматически подставит старые даты)

### Ошибка "Port 8081 is already in use"

**Причина:** Порт 8081 занят другим приложением.

**Решение:**
1. Откройте файл `server.py`
2. Измените строку `PORT = 8081` на другой порт, например `PORT = 8082`
3. Перезапустите сервер
4. Откройте дашборд по адресу `http://localhost:8082/scalper-dashboard.html`

### Ошибка "No module named 'http.server'"

**Причина:** Python не установлен или не добавлен в PATH.

**Решение:**
1. Переустановите Python с сайта [python.org](https://www.python.org/downloads/)
2. При установке отметьте галочку **"Add Python to PATH"**
3. Перезапустите командную строку

### Дашборд показывает "Нет данных"

**Возможные причины:**
1. **Выходной день** - биржа не работает, данных нет
2. **API ключ неверный** - проверьте содержимое файла `api_key.txt`
3. **Подписка истекла** - продлите подписку MOEX Algopack

**Решение:**
1. Откройте `http://localhost:8081/test-api.html` для диагностики
2. Проверьте консоль браузера (F12) на наличие ошибок
3. Убедитесь, что сегодня торговый день

## Файлы проекта

- **`server.py`** - Прокси-сервер для MOEX API
- **`scalper-dashboard.html`** - Основной дашборд
- **`test-api.html`** - Страница для тестирования API
- **`api_key.txt`** - Ваш API ключ (создайте сами)
- **`start.bat`** - Скрипт для быстрого запуска (Windows)

## Использование

### Основной дашборд

1. Откройте `http://localhost:8081/scalper-dashboard.html`
2. Данные обновляются автоматически каждые 10 секунд
3. Нажмите кнопку **"📊 Подробнее"** для детальной информации
4. Текущее время и таймер обновления отображаются внизу

### Тестирование API

Если данные не загружаются:
1. Откройте `http://localhost:8081/test-api.html`
2. Нажмите **"Тестировать API"**
3. Проверьте статус ответа и сырой ответ API

## Поддержка

Если проблема не решена:
1. Проверьте консоль сервера на наличие ошибок
2. Откройте консоль браузера (F12) и проверьте вкладку **Console** и **Network**
3. Сделайте скриншот ошибок и отправьте тому, кто дал вам этот проект

## Обновления

Если вы получили новую версию проекта:
1. Остановите сервер (Ctrl+C в консоли)
2. Замените файлы новыми
3. Перезапустите сервер
4. Обновите страницу в браузере (Ctrl+F5)

---

**Важно:** Сервер должен быть запущен всё время, пока вы используете дашборд!
