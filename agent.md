# Agent Regeln

## Arbeitsweise
- **Immer nachfragen** bevor Dateien geändert werden — niemals eigenmächtig handeln
- Bei Code-Änderungen erst den Vorschlag erklären, dann auf Bestätigung warten
- Ausnahme: Datei-Erstellungen die explizit angefragt wurden (z.B. diese agent.md)

## Projekt: MOEX Scalper Dashboard
- Python Proxy-Server (`server.py`) + Single-Page Frontend (`scalper-dashboard.html`)
- Deployed auf Render.com
- API: MOEX Algopack FUTOI (Futures Open Interest)
- Sprache: UI auf Russisch, Code-Kommentare gemischt Deutsch/Englisch
